# Support & Contribute to ERC-520

This page outlines how you can get involved with the **ERC-520 Foundation** and help build the future of **Accretive Tokens**—a groundbreaking open-source standard that combines NFT scarcity with ERC-20 liquidity and introduces built-in value accretion.

Whether through code contributions, ideas, documentation, community efforts, or voluntary financial support, every contribution strengthens this fully decentralized, community-driven initiative.

Thank you for supporting the evolution of digital ownership. Together, we're pioneering a new asset class designed for long-term value and innovation on Ethereum. 🚀
